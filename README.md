# Математика Евы

Откройте index.html. Для переноса копируйте всю папку: index.html, app.js, settings.js, EVA.png и questions/.

## Настройки в Блокноте

1. Откройте settings.js через «Открыть с помощью → Блокнот».
2. reward: 2 — награда за правильный ответ. penalty: 4 — штраф за ошибку. Введите целое число от 0 до 1000, без минуса.
3. В topics у нужной темы укажите true (включена) или false (выключена). Оставьте хотя бы одну тему.
4. Сохраните файл в UTF-8, сохранив расширение .js. Обновите страницу игры (при необходимости Ctrl+F5). Обновление начинает новую игру, поэтому сначала завершите текущую.

Не удаляйте кавычки, запятые и фигурные скобки. Настройки не читаются и не сохраняются в хранилище браузера. Панели в игре нет. Старые сохранённые браузером настройки больше не используются.

## Задания

Каждая тема находится в отдельном файле questions/*.js. В каждом файле заново созданы 100 готовых примеров и функция generate, которая формирует задание со случайными числами при каждом показе. Правильный ответ и пояснение вычисляются из тех же чисел. Чтобы изменить выдаваемые задания, редактируйте generate; массив questions содержит примеры и слоты очереди.

В задачах используются имена: Ева, папа Артур, мама Алина, брат Саша, Алла, Олег, бабушка Ира, брат Дима. Задания авторские, по темам математики 3 класса.

Включённые темы чередуются. При новом круге подбирается другой набор чисел для каждого слота; исключаются последние 300 текстов в каждой теме. Отдельные числа неизбежно встречаются снова: диапазон 3 класса конечен. Нет обещания бесконечной уникальности всех заданий. История повторов хранится только в памяти открытой страницы и сбрасывается при её обновлении.

Игра идёт до кнопки «Забрать деньги». Анимация стартового экрана учитывает системную настройку уменьшения движения.

## Проверка

node verify.cjs — проверяет банки вопросов, 10000 случайных выдач, повторные круги, имена, бесконечную игру, баланс и имитацию ответов Telegram. Реальных сообщений тесты не отправляют.
